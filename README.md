# Ветразь — проверка списков

Мобильный интерфейс для проверки фамилии и имени ребёнка, даты рождения, школы и класса, года обучения в центре.

Репозиторий содержит интерфейс. Списки детей, исправления и ключи доступа хранятся на действующем сервере и не входят в репозиторий.

## GitHub Pages

Готовая страница — `index.html` в корне. В Settings → Pages выбрать Deploy from a branch → main → /(root). Полные исходники интерфейса и сборка находятся в `source.zip`.

Ссылки для педагогов и заведующего содержат ключ в части после `#`. Ключи передаются отдельно; их нельзя добавлять в репозиторий или README.

## Сборка

Node.js 22.13+ и pnpm указанной в package.json версии:

```sh
pnpm install --frozen-lockfile
pnpm build
```

После изменения исходников пересобрать и включить папку `docs` в коммит.

## Сохранение

Списки и исправления хранятся в частной Google Таблице владельца. Сайт подключается через Apps Script: сервер проверяет ключ в каждом запросе, а служебная страница не содержит списков и ключей.

У педагогов общий ключ проверки; отдельный ключ владельца разрешает принятие и отклонение исправлений. Не публикуйте ключи или файлы с данными в репозитории.

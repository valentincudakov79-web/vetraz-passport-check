# Ветразь — проверка списков

Мобильный интерфейс для проверки фамилии и имени ребёнка, даты рождения, школы и класса, года обучения в центре.

Репозиторий содержит интерфейс. Списки детей, исправления и ключи доступа хранятся на действующем сервере и не входят в репозиторий.

## GitHub Pages

Готовый сайт — `index.html` в корне репозитория. В Settings → Pages выбрать Deploy from a branch → main → /(root).

Ссылки для педагогов и заведующего содержат ключ в части после `#`. Ключи передаются отдельно; их нельзя добавлять в репозиторий или README.

## Исходники и сборка

Полные исходники интерфейса находятся в `source.zip`. Готовая страница содержит скрипты и стили и не требует отдельной сборки на GitHub.

## Сборка

Node.js 22.13+ и pnpm указанной в package.json версии:

```sh
pnpm install --frozen-lockfile
pnpm build
```

После изменения исходников пересобрать и включить папку `docs` в коммит.

## Сохранение

API: https://vetraz-passport-check.valentincudakov79.chatgpt.site/api/passports

Сервер разрешает обращения с https://valentincudakov79-web.github.io. Доступ к данным требует действующего ключа; отдельной регистрации педагогов нет.
